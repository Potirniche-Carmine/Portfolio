GamePack

Creator & Lead Engineer In development

Offline video review, with drawings and conversations tied to the exact frame.

Architecture
Shared React Native/TypeScript interface, native macOS and Windows playback hosts, and a Rust/SQLite engine connected through CXX.
Review workflow
Organize footage into projects, annotate a frozen frame, and discuss it in threaded comments. Review playback stops at commented frames.
Engineering
I build across the interface, native media integration, and local storage, keeping playback, drawings, and comment markers in sync.
Engineering details +

AVPlayer on macOS and MediaPlayer on Windows handle native playback. Frame stepping, Watch/Review modes, and zoom connect the player to the annotation workspace.

Media imports use incremental BLAKE3 hashing and verified copies to avoid duplicate files. SQLite transactions save comments and drawings together; stable draft IDs make posting safe to retry.
